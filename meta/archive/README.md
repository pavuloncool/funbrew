# Archive

Jawne archiwum dla wygaszonych plików repo.

## Zasady

- `meta/archive/` przechowuje rzeczy historycznie istotne, które nie powinny już wyglądać jak aktywny produkt.
- Aktywny produkt pozostaje w normalnym drzewie repo: `product/apps/web`, `product/apps/consumer-mobile`, `product/packages/*`, `product/supabase/*`, source-of-truth docs.
- Nic nie trafia do `meta/archive/` bez wcześniejszej noty approval:
  - co to jest,
  - co robi dziś,
  - dlaczego nie powinno zostać w active,
  - jaki jest aktywny odpowiednik albo że odpowiednika już nie ma.
