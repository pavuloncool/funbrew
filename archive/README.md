# Archive

Jawne archiwum dla wygaszonych plików repo.

## Zasady

- `archive/` przechowuje rzeczy historycznie istotne, które nie powinny już wyglądać jak aktywny produkt.
- Aktywny produkt pozostaje w normalnym drzewie repo: `apps/web`, `apps/consumer-mobile`, `packages/*`, `supabase/*`, source-of-truth docs.
- Nic nie trafia do `archive/` bez wcześniejszej noty approval:
  - co to jest,
  - co robi dziś,
  - dlaczego nie powinno zostać w active,
  - jaki jest aktywny odpowiednik albo że odpowiednika już nie ma.

## Docelowe strefy

- `archive/apps/`
- `archive/dev-docs/`
- `archive/prompts/`
- `archive/assets/`
